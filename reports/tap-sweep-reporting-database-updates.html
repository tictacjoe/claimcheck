The Accountability Project — Reporting Database Update Sweeps

Concept & Purpose

The Reporting Database Update Sweep is an automated data ingestion pipeline that keeps The Accountability Project's reporting archive synchronized with current daily reporting.

Unlike the curated trackers (Cabinet-Level Legal Exposure, Corporate Deregulation, and Government Service Redirection), the Reporting database is a pure scrape-and-parse pipeline that requires no AI reasoning or human editorial intervention to ingest and index new articles.

Stage 1: Single-Command Ingestion Pipeline

The entire ingestion sequence is orchestrated through an automated shell script.tn When executed, this pipeline performs three distinct automated operations:

  • Archive Scraping: Queries the specified archive endpoint to identify newly published posts that do not yet exist in the local dataset.tn
  • HTML Retrieval & Parsing: Fetches the raw HTML for each newly detected article, extracting metadata, publication timestamps, authors, itemized subsections, and primary external source URLs.tn
  • Dataset Compilation: Merges the parsed stories incrementally into the reporting datastore and rebuilds the fast lookup index.tn

Stage 2: Output Validation & Local Git Staging

Once the scraper completes, the pipeline outputs the exact count of newly ingested articles, verifies dataset integrity, and commits the records to the private research repository.tn

Stage 3: Two-Repository Publishing & Live Deployment

To make the newly ingested reporting searchable on the live public site:

  • Publication Engine: Compiles the updated reporting records into the public search feeds and refreshes homepage post counters.tn
  • Public Web Repository: Deploys the static search feeds and indices live to the public web portal.tn
